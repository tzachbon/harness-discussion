Simulated call

Start call holds the microphone (like a meeting app) and reads the "Them" lines through the speakers. Hang up releases the microphone. Serve it from localhost, not file://: run uv run python -m http.server 8765 --bind 127.0.0.1 --directory docs/meetings and open http://127.0.0.1:8765/sim-call.html in Chrome, Edge, or Safari.
