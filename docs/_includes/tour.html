First run

Try everything in two minutes.

The first time it starts, a short tour has you try each feature on sample text, right in the tour window. Practice doesn't change your settings unless you keep a feature on or change a shortcut. Take the Tour in the tray or menu bar menu replays it.

  1. Allow accessOn a Mac, the Accessibility permission for shortcuts and selected text
  2. VoicePick the voice that reads to you
  3. ReadSelect text, press play
  4. RewriteFix text where you typed it
  5. ReviewSee exactly what changed
  6. DictationHold to talk
  7. Check as I typeGet fixes as you type
  8. About youTell the writing tools about you
