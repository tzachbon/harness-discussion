Privacy

Where your text goes.

Each voice source sends reading text to a different place. For local read-aloud, enable only Kokoro and Windows or macOS in Settings → Voices.

Writing and Dictation have separate source settings. For local rewrites, disable Cursor and Codex in Settings → Writing and use Local. For local dictation, keep only Local in Settings → Dictation.
