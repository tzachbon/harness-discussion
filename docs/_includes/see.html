See it

A small bar. Next to your selection.

The bar never takes focus from the app you're in. Drag or double-click to select, then press play, rewrite, or summarize.

Rewrite

Fix text where you typed it

Over text you can edit, the bar adds ✎. It rewrites the selection with your default mode and pastes it back. The toast offers Undo, Review, and another mode.

Review shows what changed. Struck-through words were removed, green words are new. Click a change to keep your original there.

Voices

You set the order

Settings → Voices lists the sources in reading order. Each row shows whether the source is ready, its voice where it has a choice, Test, arrows to move it, and an on/off switch. If one source can't read, the next one does.

On a Mac the default order is Cursor, Codex, Kokoro, then macOS. On Windows it's Cursor, Codex, Kokoro, Edge, then Windows.

Windows

The same bar on Windows

Windows has the same bar and captions, plus Edge neural voices and the built-in Windows voices. These frames come from an earlier Windows build, before ✎ joined the bar.
